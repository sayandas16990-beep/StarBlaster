# ⭐ Star Blaster

An Android game where you catch stars before time runs out!

## Features
- Fast-paced gameplay with increasing difficulty
- Score tracking and best score persistence
- Pause/Resume functionality
- Touch-optimized controls
- Beautiful gradient UI
- WebView-based implementation for easy updates

## Build & Run

1. Open in Android Studio
2. Build: `./gradlew build`
3. Run: `./gradlew installDebug`

## Play Store Submission

Before submitting:
- Update `versionCode` and `versionName` in `app/build.gradle.kts`
- Add app icon: `app/src/main/res/mipmap/ic_launcher.png` (192x192px)
- Sign APK with release key
- Complete Play Store listing
